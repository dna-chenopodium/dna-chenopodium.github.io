Chenopodium.org

Genome browsers for Quinoa and relatives

Free browsers have been set up for other crops (e.g. rice), so I thought that the world could use a quinoa one.

Code behind the project is JBrowse 2.

Links

  • Quinoa (C. quinoa)
  • Huazontle (C. nuttalliae) - native to Puebla, Mexico
  • Cañihua (C. pallidicaule) - also grown in the Andes
